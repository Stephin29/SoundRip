# SoundRip:
This is a small utility that enables DJs to search for videos from online sources and instantly download them in MP3 formats to import them into Virtual DJ.

## Features
- Quick Search: Ability to search music videos, live videos or songs using the application.

- One-Click MP3 Downloads: Ability to download songs in MP3 format by simply downloading audio from the searched videos.

- Files ready for Virtual DJ: Automatically arranged files that allow for quick dragging and dropping of songs into DJ crates.

- Lightweight and fast: The tool is built for efficiency to allow you to save on downloading time.

## Prerequisites
To be able to run the application, the below listed software must be installed on your machine:
Python(v3.8 or later recommended)
pip( Python Package manager)

## Installation
Git clone the repository:

```Bash
git clone https://github.com/Stephin29/SoundRip.git
cd SoundRip
```

Install the required packages:

```Bash
pip install -r requirements.txt
```
## Usage
Launch the program:

```Bash
python main.py
```

(Note: Change main.py with your entry point script name if its not)

Using the search bar to search your song or video.

Select your video and click Download.

Import your MP3 files into Virtual DJ and start mixing!
